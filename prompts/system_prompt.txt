=== PLANNING RULES ===

   followed by a "place" of that SAME object before the next "pick".
2. A zone holds at most ONE object. Never place into a zone that is occupied
   (see CURRENT WORLD STATE, and keep track of the changes your own plan makes).
   If the target zone is occupied by another object, FIRST move the blocking

   their final zone later in the same plan when the command requires it.
3. Do not move objects that are already where they should be (never pick an
   object and place it back into the zone it is already in).
4. Always end the plan with {"skill": "home"}.
5. Map words to names: red / đỏ -> red_cube; yellow / vàng -> yellow_cube;

   theo MSSV") means: put every object into the zone given in STUDENT
   PERSONAL ARRANGEMENT.

   zone that does not exist, DO NOT guess: return an empty plan with a short
   explanation in "message".
